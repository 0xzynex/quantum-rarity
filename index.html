How the odds are computed

The first letter isn't random

An address is a 256-bit number written in base58. Because 2256 falls between 5843 and 5844, about 94% of addresses start with 2 to H and only 1 in 999 starts with any given letter from K to z. We use the exact table, computed with integer math.

Patterns, counted exactly

Runs like 77777, digit stretches and counting runs like 12345 are scored with exact dynamic programming, so "5 of the same in a row somewhere" gets its true odds, not a guess. Words are matched in any case against a list of 230 words people recognize.

Ranked against real randomness

Each wallet is scored by its rarest pattern. We scored 2,000,000 random public keys the same way, so "rarer than 99.9%" is measured, not claimed. Beyond what the sample can show, the rank follows the exact odds.
